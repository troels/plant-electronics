#+TITLE: Plant metabolite rig
#+DATE: 2026-11-22
#+STARTUP: overview

A shelf of hydroponic plants where one computer sets the light and the
root-zone current for each group of plants, measures what the plants
produce, and searches for the recipe that produces the most.

* The approach in brief

- *Main track:* red lettuce in hydroponic jars. Red pigment (anthocyanin) is read live by camera; vitamin C is read from a small leaf sample by voltammetry.
- *Second track:* tobacco in hydroponics for nicotine, read from leaf punches by voltammetry. Slower, started in parallel.
- *Inputs the computer controls:* light intensity, spectrum (white, red, blue, UV-A, optional far-red), photoperiod, pulse frequency, and current through the root zone.
- *Weekly batches:* all plants grow under one standard light for about three weeks, then get a one-week treatment. A new batch finishes every week.
- *Method:* first reproduce effects that are already published (blue light raises redness, strong light raises vitamin C, wounding raises nicotine). Then screen the untested inputs. Then let an optimiser choose recipes.
- *One computer:* a host (desktop or Raspberry Pi) runs the scheduler, database, dashboard and analysis. One ESP32-S3 per light zone does the timing.

* What is known and what is open

| Question                                        | Status                                          |
|-------------------------------------------------+-------------------------------------------------|
| Blue or UV-A light raises lettuce redness       | Published                                       |
| Strong or continuous light raises vitamin C     | Published, with an oxidative-stress trade-off   |
| Pulsed light at equal daily dose helps          | Mixed: some studies gain, some lose             |
| Wounding or topping raises nicotine             | Published                                       |
| Near-UV raises tobacco alkaloids                | One old whole-plant study                       |
| Root-zone current changes pigment or vitamin C  | Untested for lettuce                            |
| Root-zone current changes nicotine              | Untested                                        |
| Camera can read redness                         | Published, R2 = 0.73 at canopy level            |
| Voltammetry reads vitamin C in juice            | Published; leaf extract needs your own checks   |
| Voltammetry reads nicotine in leaf extract      | Published for tobacco products; interference is the risk |
